# Dataset research — Version 2

Snapshot date: September 2026. Ranking data referenced below is the latest visible Vietnam snapshot available during implementation: **Semrush Vietnam Adult Ranking, July 2026**.

Traffic/ranking data can change over time. Rarity is a gameplay abstraction based on Vietnam traffic, brand recognition, and iconic status; it is not a quality rating.

## Method

- The visible Semrush Vietnam top 20 supplied the high-rarity core.
- Generic platforms, image hosts, forums, and directories were excluded even when Semrush classified them under Adult.
- Lower tiers supplement the Vietnam leaders with established adult-entertainment brands that preserve a varied 50-item collection.
- No adult destination URL is stored in this document or in application data.

Source codes:

- **VN-A** — Semrush Vietnam Adult Ranking, July 2026.
- **VN-I** — Semrush Vietnam ranking insights, July 2026 (named in trend/mobile/growth insights without a stable visible position).
- **GLOBAL** — Semrush Global Adult Ranking, July 2026, plus established international brand recognition; used only for the supporting lower-tier pool.
