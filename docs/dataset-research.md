# Dataset research — Version 2.1

Snapshot date: September 2026. Rarity is a gameplay balance, not a quality score or a direct traffic rank.

## Sources and method

- **SEMRUSH-VN** — [Semrush: Most Visited Adult Websites in Vietnam, July 2026](https://www.semrush.com/trending-websites/vn/adult). The public table supplies the leading 20 domains; its Vietnam insights additionally name Dit69, Phe69 and xHamsterLive.
- **AHREFS-VN** — [AhrefsTop: Top Websites in Vietnam, August 2026](https://ahrefstop.com/websites/vietnam) and its [Vietnam Reference category](https://ahrefstop.com/websites/vietnam/reference). These rankings supply Vietnam-local and Vietnamese-language brands using estimated organic search traffic.
- **GLOBAL** — established international recognition used only to fill the final 15 collection slots.

The collection contains exactly **35 Vietnam-evidenced brands** and **15 global supporting brands**. Generic image hosts, unrelated sites and duplicate mirrors were excluded. No destination URL is stored in application data and the UI never links to an adult website.

## Asset policy

The application uses local copies of public favicons or recognizable brand icons. They are brand identity only: no thumbnails, performers, screenshots or explicit imagery. If an image cannot load, the runtime shows generated initials as a true error fallback; initials are not stored or presented as primary logo assets.
